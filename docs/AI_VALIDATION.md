## Interpretation and limits

The question tests validate tools, facts and missing-data handling against synthetic fixtures. Complete scenarios supply missing details explicitly and are not defaults for real accounts. Mocked extraction does not establish live Gemini's interpretation accuracy or natural-language quality across all 150 questions. No claim of production readiness or retrained model weights is made.

Prices, payday dates, school calendars, loan interest/fees, protection of accessible cash and selected goal priorities need user input when not recorded. No external product-price source is configured. Configurable user timezones are not present in the current schema; the existing Asia/Manila calendar is retained. Translation failure preserves a deterministic English calculation with a Filipino/Cebuano introduction. The new shared token budget covers assistant provider calls; legacy scanning, dashboard insights and budget-label generation retain their existing separate quotas.

The historical accuracy follow-up did not apply a schema migration. The subsequent RAG release did apply its additive vector-knowledge migration and public-guidance index. No production deployment, paid fine-tuning or actual-account financial-data verification is claimed. See [AI_ASSISTANT.md](AI_ASSISTANT.md) for the current architecture and commands.
